Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Publish FREE with GitHub Pages:
1. Sign in or create a free GitHub account.
2. Create a public repository named swarnadeep-portfolio.
3. Upload index.html and the assets folder (keep the same folder structure).
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and / (root), then Save.
6. GitHub will show the published website address after deployment finishes.

Alternative: Netlify Drop can publish a folder by dragging it into its deploy area; check its current free-plan terms.
